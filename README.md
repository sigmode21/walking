# 人流解析ツール（検討用）

複数の出入口から多数の人が流入し、容量に限界のあるボトルネック（改札・ゲート・階段・更衣室・乗車口など）で滞留が発生する施設を対象に、**混雑・行列の発生箇所を可視化し、設計検討・改善検討を支援する**ブラウザツールです。ネットワーク型・決定論的流体近似モデル（1秒ステップで流量保存を解く）で動作し、外部ライブラリ・サーバー不要の単一HTMLファイルです。

> ⚠️ 本ツールは設計検討・確認用です。避難安全検証等の**法的用途には使用できません**。

## デモ

**GitHub Pages で公開中 → https://sigmode21.github.io/walking/**

## 主な機能

- **施設プリセット5種**: 駅改札 / イベント退場・バス乗場 / 温浴施設・更衣室 / 学校の階段 / 学生食堂。読み込むと「このシナリオの説明」ガイドが表示されます。
- **ノード編集**: 流入・分岐・滞留部・流出の配置、通路（リンク）の接続、DXF/画像の下絵取り込み。壊れたDXF・画像を読み込んだ場合はエラーメッセージを表示します。
- **モデル要素**: 一斉到着・出発（放出時間可変）、定常流入・流出の時間変化、滞留時間（浴場・食事など）、同一設備の共用（更衣室ロッカー・双方向改札など：面積・定員・処理能力の共有）、混雑回避分配、スピルバック。シミュレーション時間は最大480分（8時間）まで設定可能です。
- **可視化**: 密度ヒートマップ、行列の滞留帯、歩行者ドット、時系列グラフ4枚（行列・待ち時間・累積流入流出図・設備占有）、タイムラインのイベントマーカー。下部グラフ・右パネルはボタンで折りたたみ、狭い画面でも図面領域を確保できます。
- **出力**: 結果サマリー、CSV（設備の占有人数・滞留ノードの在圏人数を含む）、AI解釈用JSON、レポートPNG（1枚絵）。
- **作業内容の保全**: 編集内容を自動保存（2秒デバウンス）し、未保存の編集があるまま閉じようとすると確認ダイアログを表示します。次回起動時は自動保存からの復元を選べます。プリセット読込・新規作成も含めて `Ctrl+Z` で取り消せます。

## 使い方

1. ブラウザで `index.html` を開く（GitHub Pages のURLでも可）。起動直後は新規作成と同じ空の状態です（自動保存があれば復元を確認します）。
2. 「施設プリセット」からシナリオを選ぶ、または新規に配置する。
3. 「計算実行」を押し、下部のタイムライン・グラフ・図面で結果を確認する。

## 技術メモ

- 単一HTML（HTML/CSS/JavaScript）。ビルド不要。
- 計算は決定論的（乱数なし）。同じ入力は必ず同じ結果になります。
- 人を流体（連続量）として扱うため、個人単位の経路追跡は行いません。
